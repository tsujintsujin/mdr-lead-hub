# MDR Lead Hub: project summary

A working sample built for **Marketing Done Right** (a digital marketing agency
in Cleveland) as part of Justin Masiga's application for their Junior Full
Stack Developer role.

**What it does:** two lead-capture websites collect enquiries. An automation
system checks each one, scores it with a local AI model, and hands it to the
right salesperson through Slack, Asana, Google Sheets and a small CRM.

For how to run it see [README.md](README.md); for every build step see
[BUILD-LOG.md](BUILD-LOG.md).

## What's used

| Area | Tech |
|---|---|
| Websites | Two WordPress sites in **Docker**, each with its own **MySQL** database, managed with **WP-CLI** |
| Site A, "Practice Growth Check" (localhost:8081) | A custom **block theme** written as code (`theme.json` plus HTML templates) |
| Site B, "Grant Ready" (localhost:8082) | **Elementor** with the Hello Elementor theme. Pages are generated by a PHP script (`wp/site-b/build.php`) and styled with custom CSS |
| Form | Custom WordPress plugin `mdr-intake` (PHP). Checks the answers, saves them, sends them signed to n8n, and retries every 5 minutes if n8n is down |
| Automation | **n8n**, self-hosted. Workflows are generated from JavaScript (`n8n/build.mjs`) and checked by `n8n/test.js` |
| AI | **Ollama** running `qwen2.5:7b` on the PC. No paid API |
| Lead checks | **Lighthouse** (speed test of the visitor's own site) and **ProPublica's** free IRS records (nonprofit lookup) |
| CRM | **Next.js** with **SQLite** (localhost:3090) |
| Integrations | **Google Sheets** (Team tab for routing, Leads tab as a log), **Slack** (MDR Demo workspace, a channel per salesperson, buttons on each lead), **Asana** (follow-up tasks, plus an onboarding project when a lead is won), **Brevo** email (currently switched off) |
| Inbound webhooks | A **Cloudflare Tunnel** lets Slack and Asana reach n8n. Only those two paths are open |
| Tooling | Node scripts to reset the demo, seed sample leads and take phone-width screenshots. `start.cmd` launches everything |

## How a lead flows

1. The visitor fills in the 3-step form on Site A or Site B.
2. The plugin sends it to n8n, signed with a secret key.
3. n8n runs Lighthouse on the visitor's site and, for nonprofits, looks them up
   in IRS records.
4. Fixed rules score the lead (up to 70 points). The AI adds up to 30 and
   writes a summary, its reasons and an opening line for the salesperson.
5. The lead gets a verdict: Hot, Warm, Needs a conversation, Not a fit or Spam.
6. It goes to the least-busy salesperson who covers that kind of business,
   according to the Sheet's Team tab.
7. The lead is saved in the CRM, posted to Slack, given an Asana task and
   logged in the Sheet.
8. A change in any one place (Slack button, Asana tick, CRM stage) is copied
   to all the others.
9. Leads nobody has touched in 24 hours trigger a manager alert. A daily
   summary goes to `#mdr-daily` at 8:00 New York time.
